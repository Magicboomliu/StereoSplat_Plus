# FeedStereoGS
Feed-Forward 3D Gaussain Splatting 


## Dependency  
```
 pip install -r requirements.txt
```
install `diffusers` by-hand if encounter error. [Link](https://huggingface.co/docs/diffusers/training/text2image)  


## Data Preprocessing
